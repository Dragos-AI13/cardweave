# Pack 00 — Foundation

**Status:** 📝 Următorul (începe Faza 1)
**Scop:** Fundația pe care se ancorează TOATE deciziile de design. Dacă fundația e șubredă,
tot ce se construiește deasupra se clatină.

## Ce conține

- **Design Pillars** — 3-5 principii care ghidează orice decizie (propuneri în discuție:
  cărțile sunt ale tale / nimic nu se pierde / o rundă, 3 decizii / meseriile sunt cariera ta /
  lizibil dintr-o privire)
- **Core Loop final** — 30-sec loop rescris cu tot ce știm (trage → decizie → efecte → recompensă)
- **Gen & audiență** — confirmarea targetului (deckbuilder roguelike, Steam + Web, single-player)
- **Tonul jocului** — atmosfera, umorul/seriozitatea, direcția narativă de bază
- **Principii de design** — anti-patterns de evitat (ex: fără griding inutil, fără decizii false)

## Întrebări-cheie

- Care sunt pilonii finali (aprobarea celor 5 propuși)?
- Core loop-ul are exact 3 straturi de decizie sau mai simplificăm?
- Ce ton vrem: dark fantasy serios, umoristic, sau mijloc?

## Exit criteria (pachetul e gata când)

- [ ] Design Pillars aprobați și documentați
- [ ] Core Loop final rescris și aprobat
- [ ] Gen/audiență/ton confirmate
- [ ] Documente produse: `PILLARS.md`, `CORE_LOOP.md` (sau un singur `FOUNDATION.md`)
