# Pack 04 — Meta & Economy

**Status:** 📝 Neînceput
**Scop:** Ce persistă ÎNTRE run-uri — character evolution, colecția de cărți, meseriile,
monedele și economia pe termen lung. Depinde de Run (03): știm ce se câștigă într-un run
ca să proiectăm ce se păstrează.

## Ce conține

- **Character Evolution** — țăran → legendă: etape, transformări, ce deblochează fiecare
- **Colecția** — cărți/părți păstrate între run-uri, hub-ul, managementul colecției
- **Meseriile persistente** — niveluri, skill tree, rețete descoperite (progresie pe termen lung)
- **Monede** — tipuri (aur? materiale?), cum se câștigă, cum se cheltuie
- **Drop rates** — cât de des cad materiale rare, curbe
- **Costuri** — crafting, upgrade, piață: tabelul de prețuri de bază
- **Economia circulară** — fluxul complet: material → parte → carte → (folosit | dezasamblat) → material
- **Unlock-uri meta** — ce se deblochează permanent cu fiecare run (conținut, meserii, dificultate)
- **Obiective pe termen lung** — rețete legendare, specializări, transformări

## Întrebări-cheie

- Cât din colecție persistă — totul sau cu limite (sloturi)?
- Ce pierzi la moarte în run (roguelike pur) vs. ce rămâne (meta)?
- Cum evităm „grind" plictisitor — ce face progresia satisfăcătoare?
- Monedele: una sau mai multe (aur + materiale separate)?

## Exit criteria (pachetul e gata când)

- [ ] Character evolution cu etape concrete definite
- [ ] Economia completă: monede, drop rates, costuri, flux circular
- [ ] Unlock-uri meta + obiective pe termen lung definite
- [ ] Documente produse și aprobate
